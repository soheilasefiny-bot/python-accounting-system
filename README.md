# Python Accounting System

A desktop accounting application developed using **Python** and **Tkinter**.

The application is designed to simplify employee management, payroll calculations, and financial operations.

## Features

- Employee Information Management
- Salary Calculation
- Payment Records Management
- Overtime Calculation
- Monthly Salary Reports
- Custom-designed Graphical User Interface (GUI)

## Technologies Used

- Python
- Tkinter
- PNG Image Assets

## Development Capabilities

The application can be customized and developed for different languages and user requirements.

## Installation & Usage

1. Download or clone this repository.
2. Make sure Python is installed on your computer.
3. Run the main Python file.

## Project Structure

- Python source files – Application logic
- PNG files – User interface assets
- Supporting files – Additional project resources
